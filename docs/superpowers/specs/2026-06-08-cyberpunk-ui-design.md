# Cyberpunk Dashboard UI 美化设计

> Status: approved | 2026-06-08

## 目标
把三栏深蓝 tkinter 播放器改造成"萌系赛博朋克仪表盘"——有 HUD 感、不对称布局、萌宠角色 Mochi、柔和光晕零霓虹乱闪。

## 配色

- 底色: `#06060f` (极暗蓝黑)
- 主点缀: `#c084fc` (薰衣草紫), `#f0a8c0` (软粉)
- 辅点缀: `#64b4ff` (柔和蓝), `#4ecca3` (绿色状态灯)
- 文字: `#fff` / `#d0d0f0` / `#9080b0` / `#6060a0`
- 卡片底: `rgba(192,132,252,0.04-0.08)`, 边框 `rgba(192,132,252,0.08-0.15)`
- 无霓虹闪烁, 只有静态光晕 (box-shadow 模拟)

## 布局 (三栏非对称)

```
+--+--------------------+--+
|左 |      中            |右 |
|  |                    |  |
|专|    大歌词          |队|
|辑|    (22pt bold)     |列|
|封|    进度条+控件      |  |
|面|    Like/Skip/+PL    |聊|
|  |                    |天|
|品|                    |  |
|味|                    |  |
|雷|                    |  |
|达|                    |  |
|统|                    |  |
|计|                    |  |
+--+--------------------+--+
        底部状态栏
```

- **左栏** (~160px): 专辑封面 + 品味雷达条 + 会话统计
- **中栏** (flex): 大歌词显示器 + 进度条 + 控制按钮
- **右栏** (~180px): 歌曲队列 + Mochi Chat
- **底部栏**: 模式切换 + Mochi 状态

## UI 元素

### HUD 效果
- 全屏半透明扫描线 (Canvas 画条纹)
- 四角 L 形边框装饰
- 系统状态灯 (绿色圆点 + SYS OK)

### 专辑封面
- 120x120 带半透明渐变叠加
- 底边叠加文字 "TRACK 7/48"

### 品味雷达
- 横向条形图显示 Top 3 艺人权重
- 渐变条 + 数值

### 会话统计
- 三列数字: Played / Liked / Skipped
- 实时更新

### 歌词显示
- 当前行 22pt bold 白色 + text-shadow 光晕
- 多行显示 (不是只有一行)

### 进度条
- 渐变条 + 白色拖拽圆点 + 光晕

### 按钮
- 圆角胶囊形 (border-radius: 12-20px)
- 半透明背景 + 彩色边框

### 萌宠 Mochi
- 🐰 emoji 作为头像 (Canvas 画圆底 + emoji 文字)
- 聊天以 "🐰 Mochi:" 身份说话
- 底部状态 "🐰 MOCHI is listening with you"

## 约束
- tkinter 实现，不用外部库
- Canvas 绘制圆角、渐变、光晕效果
- 保持现有功能完整 (播放/评分/歌词/Chat/推荐引擎)
- 窗口尺寸不变 (1100x680)
